# Proprietary vendor files for Xiaomi Pad 8 Pro (piano)

Goes at `vendor/xiaomi/piano` in any Android 16 ROM tree (LineageOS 23.2 and
ROMs based on it). Taken from stock HyperOS firmware, so it does not depend on
the ROM. Other parts of the piano build are on the other branches; see the
[`main`](../../tree/main) branch.
